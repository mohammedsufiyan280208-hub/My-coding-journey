# Password Generator

A simple Python project that generates a random password based on the length you choose.

## Features
- Prompts the user to enter a password length
- Generates a random password using letters and numbers
- Prints the final password to the console

## Requirements
- Python 3.x

## How to Run
From the project folder, run:

```bash
python "password generator.py"
```

Then enter the desired password length when prompted.

## Example
```bash
Enter password length: 12
Your password is: aB7kL2mQx9pT
```

## Notes
This version creates passwords using uppercase letters, lowercase letters, and digits only. It does not include special symbols such as !, @, #, or $.
